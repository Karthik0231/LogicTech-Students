# LogicTech Student Solutions

Premium student-project landing site for LogicTech Solutions.

## Included
- Exact supplied LogicTech logo
- Animated hero with technology-focused background image
- Student-focused messaging and affordable-pricing section
- MERN, PHP/Laravel, React Native, Python and Go/Golang stacks
- Supporting technology logos
- Project library with real project imagery and stack filters
- Refer & Earn section with ₹500–₹1,000 qualifying referral reward
- Compact fixed enquiry form
- One-time 5-second enquiry popup (stored in localStorage so it does not reopen after being shown/closed)
- Short form fields only: Name, Phone/WhatsApp, optional College, optional Topic, optional Referred By
- FormSubmit delivery to logictech968@gmail.com

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

### Form
The forms use FormSubmit and send enquiries to `logictech968@gmail.com`. Update `_next` in `src/main.jsx` if the final success page URL differs from `https://logictech-students.vercel.app/student-project-success.html`.
